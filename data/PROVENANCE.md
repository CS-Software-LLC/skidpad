# Data provenance

Every data file used for validation or shipped as a preset must be listed here
with its source and licence. Files without an entry are not merged.

| File                                                         | What it is                                                                                              | Source                                                                                                                                                                                                                                                           | Licence           | Notes                                                                         |
| ------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------- | ----------------------------------------------------------------------------- |
| `crates/skidpad-core/tests/fixtures/synthetic_passenger.tir` | Magic Formula parameter set for a generic passenger tire                                                | Written for this project by hand; coefficients chosen to give a ~1.0 peak friction coefficient at ~7° slip angle and ~12% slip ratio at the nominal load                                                                                                         | MIT OR Apache-2.0 | Synthetic. Not measured data. Do not use for engineering decisions.           |
| `packages/presets/src/vehicles/*.json`                       | Reference vehicle definitions                                                                           | Mass, dimensions, and power figures from manufacturer press material and public spec sheets; tire feel parameters tuned to match published skidpad and braking figures                                                                                           | MIT OR Apache-2.0 | Each file carries a `dataSheet` field with its sources.                       |
| `packages/presets/src/index.ts` (`surfaces`)                 | Reference surface table                                                                                 | Friction coefficients by surface from Wong, _Theory of Ground Vehicles_, ch. 1 and Gillespie, _Fundamentals of Vehicle Dynamics_, ch. 10; rolling resistance by surface from Wong; ploughing drag from the order of magnitude of motion resistance in Wong ch. 2 | MIT OR Apache-2.0 | Each entry carries a `source` field. Class-representative, not measured.      |
| `tests/determinism/data/lap-*.json`                          | Recorded input traces of the sandbox track                                                              | Produced by `tests/determinism/src/record-lap.ts` (a scripted driver) on the core at the commit that last changed the physics; re-recorded when a milestone moves the physics                                                                                    | MIT OR Apache-2.0 | Inputs only; the replay is what the determinism check hashes.                 |
| `tools/chrono-compare/reference/*`                           | Reference runs of Project Chrono's multibody BMW_E90 for the behavioural comparison                     | Generated with PyChrono 9.0.1 (BSD-3-Clause) by `tools/chrono-compare/chrono/bmw_e90.py`, adapted from the sibling project csummers88/vehicle-physics-new (MIT, same author)                                                                                     | MIT OR Apache-2.0 | Simulator output, not measured data. See `docs/validation/chrono-bmw-e90.md`. |
| `tools/chrono-compare/src/chrono-e90.ts`                     | Constants of Chrono's BMW_E90: mass, inertia, hardpoints, rates, tire coefficients, engine map, gearing | Project Chrono 9.0.1 source, `src/chrono_models/vehicle/bmw/` (BSD-3-Clause); numbers only, each with its source file                                                                                                                                            | MIT OR Apache-2.0 | Used only to build the comparison vehicle, not a preset.                      |

Behavioural comparisons against other simulators (driving the same scenario and
comparing telemetry) are fine and should be recorded in `docs/validation/` with
the scenario, the other simulator's version, and the date.
